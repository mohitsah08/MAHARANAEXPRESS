# Devrana Express Siwan (देवरानी एक्सप्रेस सीवान)

Marketing and online presence website for Devrana Express Siwan, located at 2nd Floor, Tarwara More, Downtown City Square Mall, Siwan, Bihar 841226.

## Run locally

```bash
npm install
npm run dev
```

## Configuration

Business details and contact links are centralized in `src/config/business.ts`.
Menu items and prices are maintained in `src/data/menu.ts`.
Images and gallery assets are configured in `src/data/images.ts`.

## Verify

```bash
npm run lint
npm run build
```
